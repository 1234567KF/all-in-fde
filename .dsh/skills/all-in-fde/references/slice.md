# 切片与派发（slice）

把规格切成一组票，标依赖、分波次、派执行者。这是 Router 的核心活。

## 什么时候用

采集表 + PRD 已定，`tickets/` 为空。

## 怎么做

1. **按页面分组**：以采集表 S7 的行为单位，一个 `REQ-` 起步；耦合的多个页面合成一票，一个页面复杂时拆成多票（列表 / 表单 / 审批），拆完仍是「能单独演示的一条竖切」。
2. **定轨道**：`Base`（底座：账号、状态机、编号、共享组件）/ `Module`（业务）/ `QA`（验收）。
3. **排依赖与串并**：每票写「阻塞」与「串并」两列——阻塞管能不能开，串并管怎么开。
   - 必须串（🔗）：改同一张表/迁移、改共享契约、改注册标记
   - 可并（🔀）：纯页面切片、纯配置、纯文案、独立端
4. **分波次**：Wave 0 底座，之后按业务域分。≤5 票的项目不排波次，直接 `T-01..T-0N`。
5. **写票**：每票一个文件 `tickets/<票号>-<slug>.md`，字段如下：

```text
票号：W1-T03            （≤5 票的项目用 T-03）
标题：合同审批生效
轨道：Module
阻塞：W1-T01             （无则写「无」）
串并：🔀 并行
授权：业务方张三批准；可改 apps/web 与 packages/shared；不动契约字段；diff 超 200 行停下问
挂 REQ：REQ-C01
验收：AC-C01 / AC-C02
Spec：docs/specs/contract.md#审批
命令：脚手架模块生成命令 --name contract
三阶段：① AI 首轮 ☐   ② 人走查 ☐   ③ QA 封卡 ☐
交付回执：（做完填：Spec 路径、迁移号、接口/表摘要、下游提醒）
```

6. **排期问答**：人问「先做哪些 / 开几个 Agent」时，只回「立即可并行的票池」+「必须顺序推进的串联链」，不替人决定人数。

## 什么算完

- 每票一上下文装得下（单票改动 ≤6 文件）、做完能演示、阻塞边真实；
- 依赖无环（`scripts/check-tickets.mjs <票目录>` 退出 0；票少时也可画一张依赖表人工核对）；
- 每票验收谓词 3–5 条，且来自 S11 的 `AC-`。

## 常见错

- **按功能模块横切**（建表一张、按钮一张）：每张都演示不了。判据：这张票做完能不能当着人点一遍。
- **把「相关」写成「阻塞」**：阻塞必须是真的先做才能开，否则会造出假串行。
- **AI 代勾②③**：只勾①，②③必须等人。
- **票里抄字段表**：字段在 S7，票只引用 `REQ-` 与验收谓词。
## 派发时定档

子代理的推理档由主控按票定，默认 `low`，按难度升。四档：`off` / `low` / `high` / `max`。

### 先算难度：五个信号，命中几个

从票的字段直接读，不靠感觉。每命中一个记 1 分：

| # | 信号 | 从哪看 | 命中条件 |
| --- | --- | --- | --- |
| S1 | 动共享契约 | 授权范围 / Spec | 改 `packages/shared`、改接口形状、加枚举值 |
| S2 | 动权限或审计 | 授权范围 / AC | 新增权限点、改数据可见范围、改审计留痕字段 |
| S3 | 动金额、计算或状态机 | 验收谓词 | 出现钱、税额、汇总、守恒、状态流转 |
| S4 | 动并发、幂等或事务 | 验收谓词 | 出现重复提交、重试、锁、唯一约束、跨表写 |
| S5 | 跨端或跨模块 ≥2 | 挂 REQ / 页面 ID | 一次要改两个端或两个域的代码 |

映射（先看失败次数，再看分数）：

| 情况 | 档 |
| --- | --- |
| 连续失败 2 次（不论分数） | `max` |
| 命中 ≥4 分 | `max` |
| 命中 2–3 分 | `high` |
| 命中 0–1 分 | `low` |
| 纯文案 / 配置 / 搬数据，且 S1–S5 全 0 | `off` |

算例：合同审批票——S1 不动契约 0、S2 动权限 1、S3 有状态流转 1、S4 无并发 0、S5 列表 + 详情两页 1，共 3 分 → `high`。同一批里的「合同列表文案调整」：五项全 0 → `off`。

**为什么这么定**：这五个信号正好对应「错了难发现」的四类——契约错是全局漂移，权限错是越权，金额错是账不平，并发错是偶发。返工成本高的地方才值得多想。

### 定档三条纪律

1. **先定档再派**，不要派出去发现不对再改。
2. **升档要写理由**：回执里记一行「档位 high，因为命中 S2/S3」——没有理由的升档视为拉满。
3. **降档只降展示层**：命中 S1/S2 任何一项，最低 `high`，不许降到 `low`。
