# 验收（verify）

跑完不代表能用。这一步把「测试全绿」变成「人能用、数据对」。QA（`fde-qa` 子代理）+ 人一起做。

## 什么时候用

全部票 done，进入交付前的最终验收。

## 怎么做

1. **独立复核**：干净上下文的复核子代理，只读票 + Spec 片段 + 证据，只审不改，重跑验收谓词、核对防假绿三条。触碰共享契约/权限/认证的票必须复核，其余抽三分之一。
   - **顺序不能反**：先复核、再出 E5 证据；E5-9 的 `evidence` 指向复核记录文件。
   - 复核子代理与实现者**不同模型或不同会话**；同会话实现时（预设没装），复核必须换模型只读，并在复核记录里写「实现与复核未隔离」。
2. **冷启动清单**（不依赖测试结果，逐项记证据）：
   1. 删库重置 2. 后端冷启动，种子账号数对 3. 前端启动，端口不漂 4. 逐角色登录落对页面 5. 禁用账号被拒 / 需改密弹页 6. 核心旅程走通 7. 异常分支（403/409/空态/超长）8. 控制台无 A 类错 9. 验收卡点选 10. E2E 真实模式
3. **E2E**：阻塞四类 + 主链，无头跑门禁；核心用例两模式（无头/有头）结果一致才过 parity。视觉基线只由有头产生，证据记 `e2e.mode`、`browser.version`、`viewport`、`reducedMotion`。失败截图与 trace 落 `.fde-tmp/`，不落 `.fde/`。
4. **验收卡**：3–5 项，每项指到可打开的东西（文件行号 / 页面路由 / 截图 / 测试名），人点选；固定一项「抽 1–2 笔数据手工验算」。
5. **写证据**：`evidence/E6-<卡号>.json`，**只能**由 `scripts/card-evidence.mjs` 从填好的卡片 + 冷启动脚本证据合成（带 `signature`）。不要手写、不要用脚本把 E6-9 判 PASS。
   - 冷启动脚本产出的那份（`E6-coldstart.json`）里 E6-9 是 `SKIP`，所以它的门级 `mode` 必须是 `FAIL`——SKIP 不许冒充 PASS，校验器会拦。人点选后由卡片证据把 E6-9 写成 PASS，门级才转 PASS。

## 冷启动十步的判据（别用代理糊弄）

| 步 | 合格判据 | 常见糊弄 |
| --- | --- | --- |
| 1 删库 | 真的删掉数据目录/库文件并重建 | 用老数据跑 |
| 2 冷启动 | 新进程起、迁移与种子日志可查 | 复用常驻进程 |
| 3 前端 | 端口与配置一致 | 端口漂移 |
| 4 逐角色 | 每个角色登录落到正确首页 | 只登管理员 |
| 5 禁用/改密 | 禁用后登录被拒；改密后旧密码失效 | 只改不验 |
| 6 主链 | 一条演示路径从建到导出全走通 | 只点到列表页 |
| 7 异常 | 403 / 409 / 空态 / 超长备注各有一次 | 只测快乐路径 |
| 8 控制台 | Playwright `console` 监听，A 类错误 0 条 | 用「静态资源 200」代理 |
| 9 验收卡 | 人点选，`card-evidence.mjs` 落盘 | 脚本自判 PASS |
| 10 E2E | 真实后端 + 无头/有头 parity | 只跑 mock 或只跑无头 |

「控制台无 A 类错」的最小做法（脚本里加，不是人工看）：

```js
const errors = [];
page.on('console', (m) => { if (m.type() === 'error') errors.push(m.text()); });
page.on('pageerror', (e) => errors.push(e.message));
// …走完主链后断言 errors.length === 0，并把 errors 写进 E6-8 的 observed
```

## 分两段派：先跑后判

验收混着两种活：**跑**（执行命令、看红绿）和**判**（证据能不能证明验收、数据对不对）。一个档只能取高的，等于全程高配。所以拆两段派：

| 段 | 干什么 | 档 |
| --- | --- | --- |
| qa-run | 冷启动十步、E2E 阻塞四类、收截图与退出码 | `low` |
| qa-judge | 只读证据：验收谓词是否真被证明、数据断言是否成立、有没有假绿 | `high` |

**升 `max` 的确切条件**（满足任一）：

1. 本次判定涉及金额、权限、并发任一信号；
2. `qa-run` 报过失败，且失败点落在数据或状态上（不是环境、不是端口）；
3. 同一张票已是第二次验收。

**降 `off` 的确切条件**：只重跑一条命令复核退出码，没有任何判定动作。

两段之间**不共享上下文**：judge 只拿证据文件与票，不拿 run 的推理过程，避免先入为主——这就是「独立复核」的字面意思。

## 什么算完

- 冷启动十步全过；
- 验收卡无「有问题」，且 E6 证据 `by.kind=card`、带签名；
- E2E 阻塞四类 + 主链全绿，parity 无 diff；
- 卡上「数据手工验算」一项通过；
- `node scripts/verify-evidence.mjs .fde/evidence --strict` 退出 0。

## 常见错

- **没删库就用老数据验收**：冷启动第 1 步是删库，跳过它，全绿是假的。
- **E2E 只跑 mock**：交付前必须真实后端跑一遍，只跑 mock 不算绿。
- **拿手动截图冒充自动化证据**：截图是人卡证据（card），自动化证据必须来自脚本（script）。
- **验收卡写成「页面正常」**：不可判定的项不算项，退回改。
- **把「AI 跑通了同一条链路」当成「人确认了」**：E6-9 在人点选前只能 SKIP，门级只能 FAIL。
