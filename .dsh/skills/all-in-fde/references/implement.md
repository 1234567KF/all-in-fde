# 逐单（implement）

一票一个干净上下文：实现 + 自测 + 交证据。本文件是 Worker（`fde-worker` 子代理）的执行说明。

## 什么时候用

项目已起，有 todo 且阻塞已完成的票。

## 怎么做

1. **接单**：先读 `.fde-tmp/brief-<票号>.md`（slice 阶段自动生成），再读依赖票的「交付回执」与对应 Spec 小节，不重造。开工加载 `ponytail`，**档位随本票推理档联动**：off→lite / low,high→full / max→ultra（见 `slice.md` 定档纪律）；没装就跳过，在自测报告写一句「ponytail 未装」。Worker prompt 首行带 `#task=<票号>`（来自票面「标签」字段），供 token-budget verify 关联成本。
2. **读范围**：只读本票 + 授权范围 + 相关 Spec 片段；不读整份规格、不读别的票。
3. **实现**：红 → 绿 → 重构。先写会失败的测试，再写到通过。遵守授权范围，越界（改授权外文件、改公共接口、diff 超 200 行）即停上报。
4. **写测试**，来源不许现编：
   - 单元：S6 状态机 + S7 业务规则列 → 每条不变量至少一条负例
   - 接口：S3/S4 权限 + S11 Given → 401/403/409 各一条
   - E2E：S11 AC + S5 主链 → 阻塞四类（登录 / 菜单 / CRUD / 数据权限）
5. **数据断言**：每票至少一条数值/状态/关联断言，验在接口或库上，不验在界面上。三条红线：
   - **金额按分比较**：禁止浮点断言；期望值用整数分写死或由独立算例算出。
   - **期望值不得由实现重算**：`expect(result).toBe(sameFunction(input))` 是假绿；期望值必须来自手工算例、常量表或逆运算。
   - **守恒断言优先**：汇总 = 明细和、借贷平衡、库存出入守恒。先写守恒再写单条。
   配套门禁：E5-4 seam 预确认、E5-5 反恒真断言、E5-6 测行为不测实现。
6. **跑门禁**：`bun run check` 退出 0，并**记录这次运行的日志路径与时间**（E5-2 只认 20 分钟内的全绿日志；引用旧日志不算证据）。
   - **日志超 200 行时**：先用 `node <token-budget>/scripts/squeeze.mjs .fde-tmp/check-<时间>.log --level medium --out .fde-tmp/check-squeezed.log` 压缩，自测报告里贴压缩版，原文保留供 retrieve。

截图、日志、trace 一律落工作区根目录的 `.fde-tmp/`，不进 `.fde/`。

7. **先复核、再出证据**（顺序不能反）：
   - 涉及共享契约 / 权限 / 认证的票，先派独立复核（只读、重跑谓词）；
   - 复核结论写成 `.fde/evidence/qa-review-<阶段>.md`；
   - **QA 复核清单必检项**：Worker 输出首行是否为 `#task=<票号>`（来自票面「标签」字段）。缺失则复核记录标 WARN，供 verify 关联成本。
   - 然后写 `evidence/E5-<票号>.json`，E5-9 的 `evidence` 指向这份复核记录。
   - 同会话实现时（预设没装），复核必须**换模型只读**，并在复核记录里写「实现与复核未隔离」。

8. **写证据**：`E5-<票号>.json`。一条门一个文件：重跑时**覆盖同名文件**（或升 `revision` + `supersedes`），不要每次新建带时间戳的文件，否则校验器会按重复证据告警。

9. 附自测报告（格式见下）。

自测报告：

```text
票：W1-T03
验收：AC-C01 ✅ / AC-C02 ✅
覆盖矩阵：主路径 4/4；异常 2/3（并发审批留人工，见未覆盖说明）
负例：4（状态非法 2、权限 1、金额越界 1）
数据断言：3（金额 2、状态 1）；明细合计 = 汇总 12345.00 ✅
门禁：check 退出 0（日志 .fde-tmp/check-<时间>.log，20 分钟内）
复核：qa-review-v2.md（独立 / 换模型 / 未隔离，三选一）
未覆盖说明：并发审批需两人同时操作
证据：evidence/E5-W1-T03.json
```

10. **填交付回执**，勾 `① AI 首轮实现`。不勾 ②③；进度写进回执正文，**禁止用 ◐ 这类第三态符号**（`check-tickets.mjs` 会拦）。

## 什么算完

- 验收谓词逐条有证据；
- 数据断言不为零；
- 门禁绿，测试不是恒真（seam 预确认、反恒真、测行为不测实现）；
- 失败连续两次即停，改票（拆小或改判据），不许第三次盲试。

## 常见错

- **只测快乐路径**：负例与异常分支必须有。
- **用实现重算期望值**：自己证明自己，测不出错。
- **UI 点通就当过**：财务/业务数据必须落到接口或库上的断言。
- **顺手扩范围**：超出授权范围先停，重新开票，不自己补。
- **手写证据 JSON**：证据由脚本产出；agent 只读。
- **证据按时间戳堆三份**：一条门一个文件，重跑覆盖。
- **先出证据后复核**：E5-9 引用一份还不存在的复核记录，等于假证据。
