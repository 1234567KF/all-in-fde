# 起架（scaffold）

用脚手架把空目录变成能跑的项目，跑一次空门禁。不写业务代码。

## 什么时候用

票已切好、项目目录还没初始化。

## 怎么做

1. **环境自检**（E0）：运行时版本、git、端口、依赖、磁盘；跑 `scripts/e0-selfcheck.mjs`，退出码 0 才往下。
2. **生成项目**：用项目脚手架生成（monorepo 或平铺），端清单来自采集表 S4/S7 的「端」列。
3. **起服务**：启动前后端，确认端口与配置一致，不漂。
4. **跑空门禁**：`bun run check` 退出 0；首页能开、登录可用。
5. **写证据**：`evidence/E3-*.json`（E3 检查项）+ E0 环境证据。

## 什么算完

- E0 全 PASS（或 SKIP 已写理由）；
- 空项目 `check` 退出 0；
- 首页与登录可用。

## 常见错

- **端口漂移**：约定端口写进配置，不靠口头；多项目同时开发时各用独立端口。
- **跳过空门禁直接写业务**：空项目不绿，后面所有绿都不可信。
- **环境问题让人肉排错**：走 E0 向导，一次生成、重复可用，不逐条手工修。
