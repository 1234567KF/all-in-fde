# PPT/演示 playbook

适用于 PPT、幻灯片、汇报材料、课件、路演 deck。

## 1. 任务前：先定故事线

1. 受众、场合、时长、页数上限。
2. 一句话主线 + 3–5 个章节。
3. 选模板/技能：`dashi-ppt`、`ppt-master`、`html-ppt`、`guizang-ppt`。
4. 素材清单：已有图片/数据/logo；缺的用占位，不编造数据。
5. 判断峰谷：批量生成放低谷；改一页可高峰做。

## 2. 生成：artifact-first

- 用模板/脚本生成文件，不在对话里手写整页 HTML。
- 图片、字体、logo 落盘到项目目录，引用相对路径。
- 一次生成 3–5 页后检查，避免 30 页全生成再返工。
- 需要并行比较风格时，用子代理各跑一套，brief 写同一份内容、同一页数、只回路径和评分。

## 3. 对话里只给

1. 文件路径（pptx/html/pdf）；
2. 页数与章节；
3. 3 条设计说明；
4. 需要人工替换的占位项。

不要把 HTML、base64 图片、整页文案贴进对话。

## 4. 返工

- 先让用户看 2–3 页样张，再批量生成。
- 修改按页/按元素，不整份重做。
- 每轮记录“改了哪页、为什么”，避免反复。

## 5. 验收清单

- [ ] 页数符合要求，无空页
- [ ] 数字/结论有来源，占位项已标注
- [ ] 文件可离线打开，字体/图片不丢
- [ ] 没有把 HTML/大图贴进对话
- [ ] 有 `#task` 标签，便于 `verify`
