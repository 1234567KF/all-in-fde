# AI 味词汇规避规则（可粘贴派生快照）

> **派生声明**：本文件是 `SKILL.md` + `references/` 的**自包含快照**，用途是整份粘贴到
> 别处当系统提示 / 写作规则 / 审稿清单。规则真相源在 `SKILL.md`，词库真相源在
> `references/lexicon.md`，预算数值真相源在 `references/contexts.md`。
> 改那三处时 MUST 同步本文件；本文件与它们冲突时，以那三处为准。
> 在 DSH 内使用时直接加载 SKILL.md，不必粘贴本文件。

## 零、先判断语境

写任何文字前，先回答：
1. 谁在说（个人 / 员工 / 官方 / 品牌）
2. 对谁说（朋友 / 同事 / 领导 / 客户 / 公众 / 同行 / 评审专家）
3. 什么体裁（情感 / 故事 / 社媒 / 营销 / 汇报 / 技术 / 法律 / 医疗 / 公文 / 学术 / 标书 / 专利 / 标准）
4. 什么平台与公开度（朋友圈 / 小红书 / 公众号 / 企业 IM / 官网 / 内部文档 / 对外投标 / 报批）

**核心原则**：同一个词在技术文档里是术语，在情感文里是噪音。先定语境，再定词汇预算。判断 AI 味看密度，不看单个词。
四问答不全时按最严的合理档处理并注明假设，不要默认按"技术文档"放行。

## 一、禁用与限用词表

分级前缀 `AF-` 用于与审查发现严重度 A/B/C/X 区分，两套字母含义不同。

### AF-A1（纯黑话，任何语境都无技术定义，不因"专业"豁免）
赋能、抓手、颗粒度、打法、组合拳、心智、势能、飞轮、护城河、底层逻辑、第一性原理、降本增效、精细化运营、生态位、壁垒、水位线、卡点、堵点、痛点、痒点、爆点、基本盘、工具箱、路线图、责任田、落脚点、着力点、切入点、突破口、场域、锚点、对焦、反哺、穿透、动能、杠杆

### AF-A2（语境词，专业语境有定义即保留，私人表达是噪音）
闭环、对齐、拉通、拉齐、沉淀、复用、链路、全链路、端到端、范式、方法论、体系化、常态化、长效化、落盘、口径、打磨、拆解、收敛、透传、打通、复盘、迭代、落地、生态

**生造的管理腔**（借别的行业的词指代文档流程，一律换掉）：门控 → 校验/规则/放行条件；门禁 → 检查/能不能过；台账 → 清单/记录表；核销 → 逐条确认/勾掉；漂移 → 不一致/对不上。
「口径」分两种意思：数据语境写"计算定义、按什么算"，管理语境写"标准、要求"。

**A1/A2 判定顺序**：先问这个词在本段有没有定义或具体指代——有就留，没有才按剂量判。

### AF-B（工程/数据腔，只在对口专业语境使用）
埋点、灰度、降级、兜底、熔断、限流、幂等、解耦、编排、可观测性、鲁棒性、健壮性、基线、回归、全量、增量、快照、回滚、容灾、双活、灾备、数据治理、数据血缘、漏斗、留存、转化、触达、拉新、促活

### AF-C（公文/汇报套话，只在真实公文语体使用）
高度重视、深刻认识、统筹推进、精准发力、持续发力、久久为功、抓铁有痕、下好先手棋、对标对表、压实责任、狠抓落实、形成合力、树立标杆

### AF-D（空转形容词，必须有事实验证）
深刻、全面、系统、精准、高效、强大、丰富、多元、多维、全方位、多层次、高水平、高质量、新格局、新篇章

### AF-E（连接词与万能句式，控制密度）
首先/其次/此外/值得注意的是/综上所述/归根结底；不仅…而且…/不是…而是…/随着…的不断深入/为…注入了强劲动力/未来可期

### AF-F（元话语与自我表演，任何文体的交付正文都禁用）

这类 AI 味不靠词汇，靠"AI 在输出里谈论自己"：汇报自己遵守了什么规则、罗列自己没干什么、展示思考过程、显得聪明、替读者下判断。

**1. 规则汇报（邀功）**
- "按照你提供的规则，我避免了…"
- "这次我没有使用'赋能、抓手'这类词"
- "我已严格遵循真实第一原则"
- "以下是符合要求的版本，我做了如下调整：…"
- "我特意把'落盘'改成了'保存'"

**2. 自证清白（免责声明）**
- "本次全部是本地文件操作，没有调用任何联网工具"
- "我没有擅自改动其他文件"
- "未做任何多余修改 / 没有引入任何额外改动"
- "不包含任何占位符"
- "我没有多想，直接按你说的做"
- 用一串"我没干什么"给自己背书。没联网、没改别的文件、没有多余内容都是默认状态，不是成果，整句删掉。真有限制或没做完的部分，只说那一条。

**3. 过程外显（思考泄漏）**
- "让我先分析一下你的需求"
- "我先判断体裁，再确定词汇预算"
- "我核对了密度：A 级词 0 个，符合预算"
- "我的改写思路是…"
- "第一步…第二步…"（在描述 AI 自己的操作，而不是内容本身的步骤）

**4. 原则声明（说教）**
- "写作的第一原则是真实"
- "好的文案应该…"
- "我认为最重要的是…"
- "真正重要的是…"（未经请求地替用户定优先级）

**5. 自作聪明（替用户解读）**
- "其实你真正想要的是…"
- "这背后的本质是…"
- "很多人没意识到…"
- "让我帮你翻译成人话 / 说人话就是…"
- "这里有个反直觉的点"
- "你可能没注意到…"

**6. 降维与助手腔**
- "简单来说 / 通俗地讲 / 小白也能看懂"
- "你可以理解为…"
- "希望这对你有帮助"
- "如果你还有其他问题，随时告诉我"
- "需要我继续优化吗"
- "以上是我的回答"

**处理原则**：只交付结果。用户要改哪里、为什么改，等用户问再说；用户没问需求是否理解正确，就不要替用户重新定义需求。
**例外**：工作稿（检查报告、改动清单、事实核对记录）不受 AF-F 约束；AF-F 只管交付正文。第一人称创作中的"我"是内容角色，不是 AI 自己。

## 二、密度上限（每千字经验阈值）

`术语不限` = 该级在本档属正当术语，不做密度阻断，但仍受硬性禁令与误伤清单约束。

|---|---|---|---|---|---|---|

| `social` | 社媒个人分享 / 口播 | 0 | 0–1 | 0 | 0 | ≤2 |
| `marketing` | 营销 / 产品文案 | 0 | ≤2 | ≤1（真实技术点） | 0 | ≤3 |

折算与分布：
- 短文（<300 字）按整篇计数，出现 1 个 A1 词即判超预算。
- 长文按 `count / 字数 × 1000` 折算，字数只计正文（不含代码围栏、表格分隔行、URL）。
- 单段 A1+A2 ≥3 个，即使全篇未超预算也判超标；纯 A2 堆叠在专业档降为警告，交审查者判断有没有定义。
- 连续 ≥3 个四字格且其中含公文套话，不论文体一律超标。

## 三、硬性禁令（不论文体）

1. 禁止连续 3 个以上四字格（"高度重视、统筹推进、精准发力"）。
2. 禁止抽象名词作主语 + 抽象动词作谓语（"赋能增长""打造闭环""形成合力"），除非后文立刻给出具体指代。
3. 禁止结尾升华、口号、金句（"未来可期""书写新篇章""让我们拭目以待"）。
4. 禁止无来源的空引用（"数据显示""研究表明""专家指出"）：要么给来源，要么删。
5. 禁止为凑字数写"正确但无信息"的平衡句（"既要看到机遇，也要警惕挑战"），除非说明具体风险、谁承担、怎么处理。
6. 禁止用排比制造气势代替论证；排比只在确有并列事实时使用。
7. 禁止在输出里汇报"已按规则 / 已避免某词 / 已通过自检"，也禁止罗列"没联网 / 没改别的文件 / 没有多余改动 / 不包含某物"给自己背书。
8. 禁止未经请求展示分析过程、改写思路、评分或自我评价。
9. 禁止替用户判断"你真正想要什么"，禁止评价自己的输出"更自然 / 更有网感"。
10. 禁止"简单来说 / 说人话"式俯视读者；需要解释就直接解释。
11. 禁止模板化助手结尾（"希望这对你有帮助 / 随时告诉我"）；确需确认时用一个具体问题。

## 四、改写方向

1. 名词化 → 动词 + 对象："对路径进行优化" → "把注册从 5 步减到 3 步"。
2. 抽象 → 结果/数字："赋能团队" → "给团队多配了一块看板，周报从 4 小时缩到 1 小时"。
3. 删连接词，用时间、因果、动作顺序衔接。
4. 四字格连用拆成一句白话。
5. 结尾落在动作、事实或朴素判断。
6. 保留术语：专业文本只换"无信息"的部分，不换"有定义"的部分。

## 五、例外（保留原词）

- 引用原文、合同条款、法规条文、技术规范、医疗诊断、学术引文。
- 用户明确要求公文、技术文档、行业术语或正式风格。
- 品牌名、产品名、系统字段名（如数据文档里的"口径"、运维手册里的"落盘"）。
- 翻译任务中的源文术语和行业固定说法（适应证、久期、不可抗力）。
- 并列规范术语不是套话："国家标准、行业标准、团体标准"保留。

**冲突优先级**：用户显式风格要求 > 事实与术语准确性 > 预算档 > 通用改写方向。
保真永远高于去味：删词会损失定义、数字或限定条件时，保留该词，改周边空转部分。

## 六、交付前自检

可判定项（密度、四字格、空引用、结尾升华、元话语、连接词密度）应由脚本扫描，不用目测。
以下是脚本判不了的语义项：

- [ ] 是否先判定语境并选对预算档？
- [ ] 每个抽象词是否落到具体对象、动作或结果？
- [ ] AF-D 形容词背后有没有可核对的年月、编号、参数区间、可点名对象？
- [ ] 是否误伤了术语准确性（技术/法律/医疗）？A2 词在本段有没有定义？
- [ ] 事实、数字、限定条件、风险提示是否完整保留？
- [ ] 是否把正式文本过度口语化，或把私人文本写成公文？
- [ ] 有没有"正确但无信息"的平衡句、用排比代替论证？
- [ ] 抽象名词作主语的句子，后文有没有立刻给出具体指代？

## 七、最小示例

| 场景 | 不合格 | 合格 |
|---|---|---|
| 情感 | 共同经历了情感的沉淀与升华，未来可期 | 这一年我们吵过很多次，也一起熬过了你换工作那阵子 |
| 文案 | 全面赋能商家，打造全链路闭环 | 上架从 6 步压到 3 步，批量改价一次 500 个商品 |
| 汇报 | 围绕降本增效，深化精细化运营，取得显著成效 | 排班从三班并成两班，成本降 8%，响应时间从 5 分钟变 8 分钟 |
| 标书 | 全面赋能采购方数字化转型，技术实力行业领先 | 入库、盘点、出库接进同一套编码，盘点从 3 人 2 天改为 1 人 4 小时 |
| 技术 | （保留）触发熔断，任务落盘到本地队列 | 不改；面向非技术读者时改为"先停掉调用，把任务存到本地" |
| 标准 | （保留）适用于国家标准、行业标准、团体标准未覆盖的场景 | 不改；并列规范术语不是四字格套话 |
| 元话语 | 按你的规则我避免了黑话，先判断了体裁，改后更自然，希望有帮助 | 直接给改好的那段文字，不汇报过程 |
