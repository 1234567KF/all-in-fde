# 语境判定与词汇预算

本文件是**词汇预算的唯一真相源**。SKILL.md 只列档名与判定流程，不复制数值；
`AI味词汇规避规则.md` 是可粘贴的派生快照，数值以本文件为准。

## 1. 判定四问

写或改任何文字前，先回答：

1. **谁在说**：个人 / 员工 / 官方 / 品牌
2. **对谁说**：朋友 / 同事 / 领导 / 客户 / 公众 / 同行 / 评审专家
3. **什么体裁**：情感 / 故事 / 社媒 / 营销 / 汇报 / 技术 / 法律 / 医疗 / 公文 / 学术 / 标书 / 专利 / 标准
4. **什么平台与公开度**：朋友圈 / 小红书 / 公众号 / 企业 IM / 官网 / 内部文档 / 对外投标 / 报批

四问答不全时，按**最严的合理档**处理，并在改写说明里注明假设；不要默认按"技术文档"放行。

## 2. A 级的两个子类（决定能不能硬门禁）

A 级黑话不是同一种东西。混在一起判，必然误伤技术术语：

- **A1 纯黑话**：任何语境都没有技术定义，只用来制造气势。
  赋能、抓手、打法、组合拳、心智、势能、飞轮、护城河、底层逻辑、第一性原理、
  颗粒度、降本增效、精细化运营、生态位、基本盘、责任田、场域、锚点、水位线、
  卡点、堵点、痛点、痒点、爆点、落脚点、着力点、切入点、突破口、对焦、反哺、穿透
- **A2 语境词**：在技术/数据/运维语境里有明确定义，在私人表达里是噪音。
  闭环、对齐、拉通、拉齐、沉淀、复用、链路、全链路、端到端、范式、方法论、
  体系化、常态化、长效化、落盘、口径、打磨、拆解、收敛、透传、打通、复盘、迭代、落地

判定顺序：**先问这个词在本段有没有定义或具体指代**。有 → 保留（A2 在专业档不计入超预算）；
没有 → 按剂量判。A1 无论什么体裁都不因"专业"而豁免。

## 3. 预算表（每千字）

`术语不限` = 该级在本档属正当术语，不做密度阻断，但仍受「硬性禁令」与「误伤清单」约束。
数值为经验阈值，不是硬指标；同一段集中出现比全篇均匀分布更可疑。

| 档 ID | 语境 | A1 | A2 | B | C | D |
|---|---|---|---|---|---|---|
| `personal` | 情感 / 故事 / 个人表达 | 0 | 0–1 | 0 | 0 | ≤1 |
| `social` | 社媒分享（朋友圈/小红书/微博/口播） | 0 | 0–1 | 0 | 0 | ≤2 |

### 正式文档为什么单列档

标书、申报书、专利、标准过去只能套"公文"或"技术文档"，两者都不对：
套公文会放行"高度重视、统筹推进"，套技术文档会放行"闭环、赋能"。
这些文体的真实要求是**术语精确 + 每个判断挂在可核对对象上**，所以：

- A1 一律 0——评审专家不会因为"赋能"给分，只会觉得空。
- C 级仅 `application` 留 ≤1 且须有事实（申报书确有语体惯性），其余为 0。
- D 级必须可核验：形容词后面没有年月、编号、参数区间、可点名对象，就删。
- B 级放行：标书和标准里的工程术语是信息，不是噪音。

## 4. 折算与分布规则

- **短文（<300 字）**：按整篇计数，不折算。出现 1 个 A1 词即判超预算。
- **长文**：按 `count / 字数 × 1000` 折算，字数只计正文（不含代码围栏、表格分隔行、URL）。
- **分布**：单段 A1+A2 ≥3 个，即使全篇未超预算也判超标——集中堆叠比均匀分布更像 AI。含 A1 词记 AF-01；纯 A2 堆叠记 AF-02，在专业档降为 WARN（这些词在该语境可能有定义，脚本判不了，交审查者）。
- **四字格**：连续 ≥3 个四字格（顿号/逗号/空格分隔）不论文体一律超标。

## 5. 冲突处理优先级

1. 用户显式指定的风格要求（"就要公文腔""保留行业黑话"）
2. 事实与术语准确性（技术/法律/医疗的定义、数字、限定条件、风险提示）
3. 本文件的预算档
4. 通用改写方向

**保真永远高于去味。** 删掉一个词会损失定义、数字或限定条件时，保留该词，改周边空转部分。
