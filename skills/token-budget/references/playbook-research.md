# 调研/对比 playbook

适用于技术选型、竞品分析、方案调研、文献综述。

## 1. 任务前：问题清单

- 把“调研 X”拆成 5–10 个可回答的问题。
- 列出候选来源：官方文档、GitHub、论文、价格页、用户评价。
- 明确输出：对比表、结论、风险、引用。

## 2. 取证：子代理并行

- 每个来源/子问题一个子代理，brief 写明：问题、允许访问的来源、返回上限 1500 token、引用 URL。
- 子代理把详细笔记写文件，回复只给 3 条结论 + 引用。
- 主线程只做交叉验证和综合，不搬运原文。

## 3. 结论

- 先给结论，再给证据；每条结论至少一个可点击来源。
- 区分“官方事实”“第三方测量”“推测”。
- 价格/版本/日期写清楚，避免过期数据。
- 不确定就写“未验证”，不编造。

## 4. 交付

1. 结论摘要（3–5 条）；
2. 对比表（维度 × 候选）；
3. 风险/未知；
4. 参考链接。

不要把整页网页内容贴回对话；引用 URL + 一句话即可。

## 5. 验收清单

- [ ] 每个关键结论有来源
- [ ] 价格/版本/日期是最新的
- [ ] 区分事实与推测
- [ ] 子代理没有回传大段原文
- [ ] 有 `#task` 标签，便于 `verify`
