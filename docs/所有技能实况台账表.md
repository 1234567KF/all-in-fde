原因：

1. `all-in-fde` 入口技能不存在：`skills/all-in-fde` 与 `.dsh/skills/all-in-fde` 均不存在。
2. 没有任何技能的 `SKILL.md` 显式 `skill <name>` 调用其他技能，也没有声明 `dependencies.skills`。
3. `token-budget/SKILL.md` 里只写了“以后有 all-in-fde 入口时，在入口第一步加载 token-budget”的说明，这是**接入约定**，不是绑定。

绑定后应该是什么样：

```text
all-in-fde/SKILL.md 第一步：
  先加载 token-budget 技能，执行 plan。

all-in-fde 路由表：
  doc → all-in-md
  ppt → dashi-ppt / ppt-master / html-ppt / guizang-ppt
  code → 直接执行
  research → anysearch + 子代理
```

在这种结构出现之前，所有技能都是“DSH 直接按需加载”，不经过 all-in-fde。
