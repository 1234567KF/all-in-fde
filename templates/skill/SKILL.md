# Example Skill

一句话说明这个技能交付什么。

## 什么时候用

- 用户要做的事情 A
- 用户提到关键词 B、C

## 不做什么

- 边界之外的事情，写清楚，避免误触发。

## 步骤

1. 第一步：读什么、判断什么。
2. 第二步：产出什么。
3. 第三步：怎么验收。

## 目录

| 路径 | 内容 |
| --- | --- |
| `references/` | 引用资料 |
| `scripts/` | 可执行脚本 |
